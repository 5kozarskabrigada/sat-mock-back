# SAT Mock Exam Platform - Deployment Guide

## Architecture Overview
- **Backend**: NestJS API with direct PostgreSQL connection (Render)
- **Frontend**: Next.js UI calling backend APIs (Vercel)
- **Database**: Neon PostgreSQL (hosted)

## 1. Database Setup (Neon PostgreSQL)

Your database is hosted on Neon. Connection string format:
```
postgresql://neondb_owner:PASSWORD@ep-sparkling-heart-al64ging.c-3.eu-central-1.aws.neon.tech/neondb?sslmode=require
```

### Run Migration Locally (First Time)
```bash
cd api
npm run migrate    # Creates all tables
npm run seed       # Creates admin user (admin@satmock.com / admin123)
```

## 2. Backend Deployment (Render)

### Method 1: Using render.yaml (Recommended)
1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click **New +** → **Blueprint**
3. Connect your GitHub repository
4. Select the `api` folder
5. Render will detect `render.yaml` automatically
6. **Set Environment Variables**:
   - `DATABASE_URL`: Your Neon PostgreSQL connection string
   - `JWT_SECRET`: Auto-generated by Render (or set your own 32+ char string)
   - `CORS_ORIGIN`: `https://your-vercel-app.vercel.app,http://localhost:3000`
7. Click **Apply** to deploy

### Method 2: Manual Setup
1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click **New +** → **Web Service**
3. Connect your repository
4. **Settings**:
   - Name: `sat-platform-api`
   - Environment: `Node`
   - Build Command: `npm install && npm run build && npm run migrate`
   - Start Command: `npm run start:prod`
   - **Environment Variables** (see above)
5. Create Web Service

### Post-Deployment
- Your API will be available at: `https://sat-platform-api.onrender.com/api`
- Test health check: `https://sat-platform-api.onrender.com/api`
- Migration runs automatically during build

## 3. Frontend Deployment (Vercel)

1. Go to [Vercel Dashboard](https://vercel.com/dashboard)
2. Click **Add New** → **Project**
3. Import your repository
4. **Framework Preset**: Next.js
5. **Root Directory**: `web`
6. **Environment Variables**:
   ```
   NEXT_PUBLIC_API_URL=https://sat-platform-api.onrender.com/api
   ```
7. Deploy

### Update CORS After Deployment
Once your Vercel app is deployed, update the backend's `CORS_ORIGIN` environment variable in Render:
```
CORS_ORIGIN=https://your-app.vercel.app,http://localhost:3000
```

## 4. Database Migration

### Initial Setup (First Time Only)
```bash
# From api folder
npm run db:setup
```

This will:
1. Create all tables (Better Auth + Application tables)
2. Set up indexes for performance
3. Create admin user: `admin@satmock.com` / `admin123`

### Future Migrations
Add new `.sql` files to `api/migrations/` and update the migration script.

- **Vercel Logs**: Dashboard → Your Project → Deployments → View Function Logs

## 8. Troubleshooting

### Migration Fails on Render
- Check DATABASE_URL is set correctly
- Ensure Neon database is accessible
- Check Render build logs

### CORS Errors
- Verify CORS_ORIGIN includes your Vercel domain
- Check browser console for exact error
- Ensure no trailing slashes in URLs

### 500 Errors
- Check Render logs for stack traces
- Verify all environment variables are set
- Test database connection
